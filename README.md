# DEEPPULSE RECORDS Website

Premium Next.js website for DEEPPULSE RECORDS.

## Deploy

Upload this repository to GitHub, then connect it to Vercel or another Next.js host.

Set these environment variables in the host dashboard:

```bash
SPOTIFY_CLIENT_ID=
SPOTIFY_CLIENT_SECRET=
SPOTIFY_PLAYLIST_ID=3otNJ0MhB3MmCsZfsZkkvc
MANUAL_REFRESH_SECRET=
```

Do not commit `.env.local`.

## Local Development

```bash
npm install
npm run dev
```
